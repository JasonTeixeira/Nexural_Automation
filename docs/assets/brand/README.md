# Nexural Automation brand assets

The NX mark is an original angular monogram: acid lime identifies verified system flow and
safety orange identifies intervention or risk. Warm paper carries primary copy; institutional
charcoal is the default field.

Use `nx-mark.svg` for square avatars and application identity,
`nexural-automation-wordmark.svg` on transparent or charcoal surfaces, and
`nexural-automation-lockup.svg` when the mark and name must travel together.

Do not recolor the mark with blue or purple, add gradients, separate the N and X, redraw it with
third-party platform branding, or place it over market screenshots.
